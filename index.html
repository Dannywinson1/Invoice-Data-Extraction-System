Architecture

How the engine works

01

PDF Ingestion

Accepts any PDF. Text-based PDFs are parsed natively via geometry; image PDFs pass through OCR.

02

Layout Analysis

Spatial coordinates of every text block are mapped to identify tables, headers, and totals dynamically.

03

Field Extraction

Named fields are located using positional heuristics and regex patterns validated across thousands of layouts.

04

JSON Output

Data is normalized and emitted as a strictly typed JSON object with confidence scores attached.
